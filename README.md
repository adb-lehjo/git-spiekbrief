# git-spiekbrief
# Mijn spiekbrief voor Git en Github
## 1. Clone, commit, push en pull

met clone dowload je een project van github naar je eigen computer 
met commit sla je zelf op wat hebt gedaan
met push stuur je dit van je computer naar github 
met pull haal je de laatste wijziging van github naar je computer 

## 3. GitIgnore
dit zorgt ervoor dat git ongewenste betsanden negeert en niet uploadt naar github

dit laat je code zien dat je in VS code hebt geschreven en gepushed 

## 4.Pull toe 
als iemand anders iets wijzigd in je code en je niet pulled dan zie je de weizigingen niet nu wel.
